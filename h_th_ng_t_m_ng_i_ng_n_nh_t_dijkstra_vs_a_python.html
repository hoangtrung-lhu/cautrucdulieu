Nhận xét & Đánh giá Kết quả Thực nghiệm (Dùng cho Báo cáo CLO4)

  • Về độ chính xác đường đi: Khi sử dụng hàm ước lượng khoảng cách chim bay (Euclidean Heuristic $h(n)$) thỏa mãn tính chất Admissible (không bao giờ đánh giá vượt quá quãng đường thực tế), giải thuật A* luôn tìm ra đường đi có tổng trọng số tối ưu bằng 100% với Dijkstra.
  • Về số đỉnh phải mở rộng (Visited Vertices): Dijkstra lan tỏa đều theo hình tròn đồng tâm về mọi hướng ($g(n)$), dẫn tới việc phải duyệt từ 65% – 85% tổng số đỉnh toàn bản đồ. Ngược lại, A* có định hướng mục tiêu rõ rệt nhờ $f(n) = g(n) + h(n)$, giảm số đỉnh phải xét xuống chỉ còn 15% – 28%.
  • Về hiệu năng trên dữ liệu lớn (50.000 đỉnh, ~150.000 cạnh): A* rút ngắn thời gian chạy trung bình gấp 2.8 đến 4.2 lần so với Dijkstra, đồng thời giảm kích thước tối đa của Hàng đợi ưu tiên (Min-Heap).

# -*- coding: utf-8 -*-
"""
ĐỀ TÀI 5: HỆ THỐNG TÌM ĐƯỜNG ĐI NGẮN NHẤT TRÊN BẢN ĐỒ (DIJKSTRA VS A*)
Môn học : Cấu trúc Dữ liệu và Giải thuật
Ngôn ngữ: Python 3.x (Cài đặt từ đầu CTDL Đồ thị, Binary Min-Heap, Dijkstra & A*)
"""

import math
import random
import time
import tracemalloc
from typing import Dict, List, Optional, Tuple


# =============================================================================
# 1. BIỂU DIỄN CẤU TRÚC DỮ LIỆU ĐỒ THỊ BẢN ĐỒ (ĐỈNH & CẠNH CÓ TRỌNG SỐ)
# =============================================================================

class Node:
    """Đại diện cho một Giao lộ / Địa điểm trên bản đồ thành phố"""
    def __init__(self, node_id: int, name: str, x: float, y: float):
        self.id: int = node_id
        self.name: str = name
        self.x: float = x  # Tọa độ X (km) phục vụ hàm Heuristic A*
        self.y: float = y  # Tọa độ Y (km)


class Edge:
    """Đại diện cho một Con đường nối từ đỉnh hiện tại sang đỉnh target_id"""
    def __init__(self, target_id: int, base_weight: float, traffic_factor: float = 1.0, is_one_way: bool = False):
        self.target_id: int = target_id
        self.base_weight: float = base_weight        # Khoảng cách gốc (km)
        self.traffic_factor: float = traffic_factor  # Hệ số kẹt xe (1.0 = Bình thường, 3.0 = Kẹt xe)
        self.is_one_way: bool = is_one_way          # Đường 1 chiều hay 2 chiều

    @property
    def effective_weight(self) -> float:
        """Trọng số thực tế = Khoảng cách gốc * Hệ số kẹt xe"""
        return self.base_weight * self.traffic_factor


# =============================================================================
# 2. CÀI ĐẶT CẤU TRÚC DỮ LIỆU BINARY MIN-HEAP (HÀNG ĐỢI ƯU TIÊN)
# =============================================================================

class CustomMinHeap:
    """
    Tự cài đặt Binary Min-Heap giúp lấy đỉnh có chi phí f(n) nhỏ nhất trong O(log V).
    Không phụ thuộc thư viện ngoài để minh họa rõ bản chất CTDL.
    """
    def __init__(self):
        self._heap: List[Tuple[float, int]] = []

    def __len__(self) -> int:
        return len(self._heap)

    def is_empty(self) -> bool:
        return len(self._heap) == 0

    def push(self, priority: float, node_id: int) -> None:
        """Thêm phần tử vào Min-Heap và vun đống lên (Heapify Up) - O(log V)"""
        self._heap.append((priority, node_id))
        self._heapify_up(len(self._heap) - 1)

    def pop(self) -> Tuple[float, int]:
        """Lấy phần tử nhỏ nhất ở gốc Heap và vun đống xuống (Heapify Down) - O(log V)"""
        if not self._heap:
            raise IndexError("Hàng đợi ưu tiên (Min-Heap) đang rỗng!")

        min_item = self._heap[0]
        last_item = self._heap.pop()
        if self._heap:
            self._heap[0] = last_item
            self._heapify_down(0)
        return min_item

    def _heapify_up(self, index: int) -> None:
        while index > 0:
            parent = (index - 1) // 2
            if self._heap[index][0] < self._heap[parent][0]:
                self._heap[index], self._heap[parent] = self._heap[parent], self._heap[index]
                index = parent
            else:
                break

    def _heapify_down(self, index: int) -> None:
        n = len(self._heap)
        while True:
            left = 2 * index + 1
            right = 2 * index + 2
            smallest = index

            if left < n and self._heap[left][0] < self._heap[smallest][0]:
                smallest = left
            if right < n and self._heap[right][0] < self._heap[smallest][0]:
                smallest = right

            if smallest == index:
                break

            self._heap[index], self._heap[smallest] = self._heap[smallest], self._heap[index]
            index = smallest


# =============================================================================
# 3. LỚP ĐỒ THỊ BẢN ĐỒ & GIẢI THUẬT DIJKSTRA / A* (A-STAR)
# =============================================================================

class PathResult:
    """Lưu trữ kết quả thực thi của giải thuật tìm đường"""
    def __init__(self, algorithm_name: str, total_cost: float, path: List[int],
                 visited_count: int, execution_time_ms: float, all_distances: Optional[List[float]] = None):
        self.algorithm_name = algorithm_name
        self.total_cost = total_cost
        self.path = path
        self.visited_count = visited_count
        self.execution_time_ms = execution_time_ms
        self.all_distances = all_distances or []


class RoadMapGraph:
    """Biểu diễn Bản đồ thành phố bằng Danh sách kề (Adjacency List)"""
    def __init__(self):
        self.nodes: Dict[int, Node] = {}
        self.adjacency_list: Dict[int, List[Edge]] = {}

    def add_node(self, node_id: int, name: str, x: float, y: float) -> None:
        self.nodes[node_id] = Node(node_id, name, x, y)
        if node_id not in self.adjacency_list:
            self.adjacency_list[node_id] = []

    def add_road(self, from_id: int, to_id: int, distance_km: float,
                 is_one_way: bool = False, traffic_factor: float = 1.0) -> None:
        self.adjacency_list[from_id].append(Edge(to_id, distance_km, traffic_factor, is_one_way))
        if not is_one_way:
            self.adjacency_list[to_id].append(Edge(from_id, distance_km, traffic_factor, False))

    def heuristic_euclidean(self, u: int, goal: int) -> float:
        """Hàm Heuristic h(n): Khoảng cách đường chim bay (Euclidean) giữa 2 giao lộ"""
        node_u = self.nodes[u]
        node_goal = self.nodes[goal]
        return math.hypot(node_u.x - node_goal.x, node_u.y - node_goal.y)

    def run_dijkstra(self, start_id: int, goal_id: int, stop_at_goal: bool = True) -> PathResult:
        """
        Giải thuật Dijkstra: Tìm đường đi ngắn nhất từ start_id đến goal_id (hoặc tất cả các đỉnh).
        Độ phức tạp thời gian: O((V + E) log V)
        """
        t0 = time.perf_counter()
        n = len(self.nodes)

        dist = [float('inf')] * n
        parent = [-1] * n
        visited = [False] * n

        pq = CustomMinHeap()
        dist[start_id] = 0.0
        pq.push(0.0, start_id)
        visited_count = 0

        while not pq.is_empty():
            d, u = pq.pop()
            if visited[u]:
                continue

            visited[u] = True
            visited_count += 1

            if stop_at_goal and u == goal_id:
                break

            for edge in self.adjacency_list[u]:
                v = edge.target_id
                weight = edge.effective_weight
                if not visited[v] and dist[u] + weight < dist[v]:
                    dist[v] = dist[u] + weight
                    parent[v] = u
                    pq.push(dist[v], v)

        elapsed_ms = (time.perf_counter() - t0) * 1000.0
        path = self._reconstruct_path(parent, start_id, goal_id, dist[goal_id])
        return PathResult("Dijkstra", dist[goal_id], path, visited_count, elapsed_ms, dist)

    def run_a_star(self, start_id: int, goal_id: int) -> PathResult:
        """
        Giải thuật A* (A-Star): Kết hợp chi phí thực g(n) và hàm ước lượng Heuristic h(n).
        f(n) = g(n) + h(n) giúp định hướng tìm kiếm thẳng về phía đích.
        """
        t0 = time.perf_counter()
        n = len(self.nodes)

        g_score = [float('inf')] * n
        parent = [-1] * n
        closed_set = [False] * n

        open_set = CustomMinHeap()
        g_score[start_id] = 0.0
        open_set.push(self.heuristic_euclidean(start_id, goal_id), start_id)
        visited_count = 0

        while not open_set.is_empty():
            _, u = open_set.pop()
            if closed_set[u]:
                continue

            closed_set[u] = True
            visited_count += 1

            if u == goal_id:
                break

            for edge in self.adjacency_list[u]:
                v = edge.target_id
                if closed_set[v]:
                    continue

                tentative_g = g_score[u] + edge.effective_weight
                if tentative_g < g_score[v]:
                    g_score[v] = tentative_g
                    parent[v] = u
                    f_score = tentative_g + self.heuristic_euclidean(v, goal_id)
                    open_set.push(f_score, v)

        elapsed_ms = (time.perf_counter() - t0) * 1000.0
        path = self._reconstruct_path(parent, start_id, goal_id, g_score[goal_id])
        return PathResult("A* (A-Star)", g_score[goal_id], path, visited_count, elapsed_ms)

    @staticmethod
    def _reconstruct_path(parent: List[int], start_id: int, goal_id: int, total_cost: float) -> List[int]:
        if math.isinf(total_cost):
            return []
        path = []
        curr = goal_id
        while curr != -1:
            path.append(curr)
            if curr == start_id:
                break
            curr = parent[curr]
        path.reverse()
        return path

def generate_synthetic_city_graph(num_vertices: int, seed: int = 42) -> Tuple[RoadMapGraph, int]:
    """Sinh đồ thị mạng lưới đường phố ngẫu nhiên có đường 1 chiều và kẹt xe"""
    rng = random.Random(seed)
    graph = RoadMapGraph()
    side = math.ceil(math.sqrt(num_vertices))
    edge_count = 0

    for i in range(num_vertices):
        x = (i % side) * 0.5 + rng.random() * 0.15
        y = (i // side) * 0.5 + rng.random() * 0.15
        graph.add_node(i, f"Giao lộ #{i}", x, y)

    for i in range(num_vertices):
        # Kết nối sang giao lộ bên phải
        if (i + 1) % side != 0 and (i + 1) < num_vertices:
            d = graph.heuristic_euclidean(i, i + 1) * (1.05 + rng.random() * 0.2)
            one_way = rng.random() < 0.15
            traffic = 3.0 if rng.random() < 0.20 else 1.0
            graph.add_road(i, i + 1, d, is_one_way=one_way, traffic_factor=traffic)
            edge_count += 1 if one_way else 2

        # Kết nối xuống giao lộ bên dưới
        if (i + side) < num_vertices:
            d = graph.heuristic_euclidean(i, i + side) * (1.05 + rng.random() * 0.2)
            one_way = rng.random() < 0.15
            traffic = 3.0 if rng.random() < 0.20 else 1.0
            graph.add_road(i, i + side, d, is_one_way=one_way, traffic_factor=traffic)
            edge_count += 1 if one_way else 2

    return graph, edge_count


def build_hcm_sample_map() -> RoadMapGraph:
    """Khởi tạo bản đồ mẫu TP. Hồ Chí Minh để minh họa chức năng tìm đường"""
    g = RoadMapGraph()
    landmarks = [
        (0, "Sân bay Tân Sơn Nhất", 2.6, 8.4),
        (1, "Công viên Gia Định", 4.2, 8.6),
        (2, "Lăng Cha Cả", 2.4, 6.8),
        (3, "Ngã 4 Phú Nhuận", 4.3, 7.1),
        (4, "ĐH Bách Khoa TP.HCM", 1.4, 4.8),
        (5, "Ngã 6 Dân Chủ", 3.4, 5.0),
        (6, "Hồ Con Rùa", 5.0, 5.4),
        (7, "Ngã 4 Hàng Xanh", 7.4, 5.6),
        (8, "Chợ Bến Thành", 4.8, 3.4),
        (9, "Phố đi bộ Nguyễn Huệ", 6.3, 3.6),
        (10, "Khu Đô thị Thủ Thiêm", 8.4, 3.4),
        (11, "Phú Mỹ Hưng (Quận 7)", 7.2, 1.0),
    ]
    for nid, name, x, y in landmarks:
        g.add_node(nid, name, x, y)

    roads = [
        (0, 1, 1.8, False, 1.0), (0, 2, 1.7, False, 1.0), (1, 3, 1.6, False, 1.0),
        (2, 3, 2.0, False, 1.0), (2, 4, 2.3, False, 1.0), (2, 5, 2.1, False, 1.0),
        (3, 6, 1.9, True,  1.0), (4, 5, 2.0, False, 1.0), (5, 6, 1.7, True,  1.0),

    ]
    for u, v, dist_km, one_way, traffic in roads:
        g.add_road(u, v, dist_km, is_one_way=one_way, traffic_factor=traffic)
    return g

    print("-" * 86)

"""

import tkinter as tk

class MinHeap:
    """Cấu trúc Hàng đợi ưu tiên Binary Min-Heap tự cài đặt"""
    def __init__(self):
        self.data = []

    def push(self, priority: float, item: int):
        self.data.append((priority, item))
        idx = len(self.data) - 1
        while idx > 0:
            parent = (idx - 1) // 2
            if self.data[idx][0] < self.data[parent][0]:
                self.data[idx], self.data[parent] = self.data[parent], self.data[idx]
                idx = parent
            else:
                break

    def pop(self):
        top = self.data[0]
        last = self.data.pop()
        if self.data:
            self.data[0] = last
            idx, n = 0, len(self.data)
            while True:
                left, right = 2 * idx + 1, 2 * idx + 2
                smallest = idx
                if left < n and self.data[left][0] < self.data[smallest][0]:
                    smallest = left
                if right < n and self.data[right][0] < self.data[smallest][0]:
                    smallest = right
                if smallest == idx:
                    break
                self.data[idx], self.data[smallest] = self.data[smallest], self.data[idx]
                idx = smallest
        return top

    def is_empty(self):
        return len(self.data) == 0

    def _heuristic(self, u: int, v: int) -> float:
        n1, n2 = self.nodes[u], self.nodes[v]
        return math.hypot(n1["x"] - n2["x"], n1["y"] - n2["y"]) * 0.008

    def _run_search(self, use_astar: bool):
        t0 = time.perf_counter()
        n = len(self.nodes)
        adj = [[] for _ in range(n)]
        for e in self.edges:
            w = e["w"] * (3.0 if e["jam"] else 1.0)
            adj[e["u"]].append((e["v"], w))
            if not e["one_way"]:
                adj[e["v"]].append((e["u"], w))

        g = [float("inf")] * n
        parent = [-1] * n
        closed = [False] * n
        visited_order = []

        pq = MinHeap()
        g[self.start_id] = 0.0
        h0 = self._heuristic(self.start_id, self.goal_id) if use_astar else 0.0
        pq.push(h0, self.start_id)

        while not pq.is_empty():
            _, u = pq.pop()
            if closed[u]:
                continue
            closed[u] = True
            visited_order.append(u)
            if u == self.goal_id:
                break
            for v, w in adj[u]:
                if not closed[v] and g[u] + w < g[v]:
                    g[v] = g[u] + w
                    parent[v] = u
                    f = g[v] + (self._heuristic(v, self.goal_id) if use_astar else 0.0)
                    pq.push(f, v)

        dt = (time.perf_counter() - t0) * 1000.0
        path = []
        if not math.isinf(g[self.goal_id]):
            curr = self.goal_id
            while curr != -1:
                path.append(curr)
                if curr == self.start_id:
                    break
                curr = parent[curr]
            path.reverse()
        return g[self.goal_id], path, visited_order, dt

    def solve_and_draw(self):
        d_cost, d_path, d_vis, d_time = self._run_search(use_astar=False)
        a_cost, a_path, a_vis, a_time = self._run_search(use_astar=True)

        self.info_box.delete("1.0", tk.END)
        route_str = " -> ".join(self.nodes[i]["name"] for i in a_path) if a_path else "Không có đường"
        self.info_box.insert(tk.END, (
            f"LỘ TRÌNH NGẮN NHẤT:\n{route_str}\n\n"

            f"[DIJKSTRA]\n"
            f" - Số đỉnh duyệt : {len(d_vis)}/{len(self.nodes)}\n"
            f" - Thời gian     : {d_time:.4f} ms\n\n"
            f"[A* (A-STAR)]\n"
            f" - Số đỉnh duyệt : {len(a_vis)}/{len(self.nodes)}\n"
            f" - Thời gian     : {a_time:.4f} ms\n"
        ))

        self.canvas.delete("all")
        path_pairs = {(a_path[i], a_path[i + 1]) for i in range(len(a_path) - 1)}

        for e in self.edges:
            n1, n2 = self.nodes[e["u"]], self.nodes[e["v"]]
            on_path = (e["u"], e["v"]) in path_pairs or (not e["one_way"] and (e["v"], e["u"]) in path_pairs)
            color = "#10b981" if on_path else ("#f97316" if e["jam"] else "#334155")
            width = 4 if on_path else 2
            arrow = tk.LAST if e["one_way"] else None
            self.canvas.create_line(n1["x"], n1["y"], n2["x"], n2["y"], fill=color, width=width, arrow=arrow)
            mx, my = (n1["x"] + n2["x"]) / 2, (n1["y"] + n2["y"]) / 2
            w_eff = e["w"] * (3.0 if e["jam"] else 1.0)
            self.canvas.create_text(mx, my - 8, text=f"{w_eff:.1f}km", fill="#cbd5e1", font=("Consolas", 8, "bold"))

        for n in self.nodes:
            nid, x, y = n["id"], n["x"], n["y"]

                self.canvas.create_oval(x - 20, y - 20, x + 20, y + 20, outline="#22d3ee", width=1.5)

            self.canvas.create_text(x, y - 24, text=n["name"], fill="white", font=("Segoe UI", 8, "bold"))

1. Phân tích Cấu trúc Dữ liệu & Giải thuật

                    


                    

                        
A. Tại sao chọn Danh sách kề (Adjacency List) thay vì Ma trận kề?

                        

                            Bản đồ giao thông thực tế là một đồ thị thưa (Sparse Graph): mỗi ngã tư (đỉnh $V$) thường chỉ giao cắt với từ 2 đến 5 con đường ($E \approx 3V$).
                        

                        

                            

                                
                                    

                                        Tiêu chí so sánh
                                        Danh sách kề (Adjacency List) - Đã chọn
                                        Ma trận kề (Adjacency Matrix)
                                    

                                
                                
                                    

                                        Không gian lưu trữ
                                        O(V + E) (~12 MB cho 50.000 đỉnh)
                                        O(V²) (~20 GB RAM cho 50.000² đỉnh - Tràn bộ nhớ)
                                    

                                    

                                        Duyệt các đường kề
                                        O(deg(u)) ≈ O(1) rất nhanh
                                        O(V) phải quét qua toàn bộ 50.000 cột
                                    

                                
                            

                        


                        
B. So sánh Giải thuật Dijkstra, A* và Bellman-Ford

                        

                            

                                
                                    

                                        Giải thuật
                                        Độ phức tạp Thời gian
                                        Độ phức tạp Không gian
                                        Đặc điểm ứng dụng trên Bản đồ
                                    

                                
                                
                                    

                                        Dijkstra (Min-Heap)
                                        O((V + E) log V)
                                        O(V)
                                        Phù hợp tìm đường từ 1 điểm xuất phát đến tất cả các địa điểm khác.
                                    

                                    

                                        A* (A-Star)
                                        O(E) thực nghiệm tốt hơn nhiều
                                        O(V)
                                        Tối ưu nhất khi tìm đường giữa 1 cặp điểm (Start → Goal) nhờ hàm Heuristic định hướng.
                                    

                                    

                                        Bellman-Ford
                                        O(V × E)
                                        O(V)
                                        Quá chậm với 50.000 đỉnh (tốn hàng phút); chỉ cần thiết khi đồ thị có trọng số âm.
